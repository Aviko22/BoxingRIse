# BoxingRise

Landing page for BoxingRise, premium one-on-one boxing coaching. Static site (HTML, CSS, a little JS), hosted on Vercel.

## Files
- `index.html` – the landing page (Hebrew, RTL)
- `accessibility.html` – accessibility statement (ת״י 5568)
- `styles.css` – all styles; brand colors are at the top in `:root`
- `main.js` – site settings: put the WhatsApp number in `WHATSAPP_NUMBER`
- `brand/` – logo files (logo.webp for the site, logo.png, logo-mark.png, icon-512.png)
- `favicon-32.png`, `apple-touch-icon.png` – browser and phone icons
